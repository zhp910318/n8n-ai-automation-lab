Works with any OpenAI-compatible model (default gpt-4o-mini). One LLM call per run — well under a cent.

How it works

  1. Open n8n → Workflows → Import from File → select workflow.json.
  2. Open Generate Hooks (LLM) → attach your OpenAI (or compatible) credential.
  3. Open Input → set topic, audience, tone.
  4. Click Test workflow. You get hooks — a JSON array of { style, text }.

FAQ

Do I need a paid n8n plan?

No. The workflow runs on n8n Cloud or a self-hosted n8n. You only need an OpenAI-compatible API key.

Is the Hook Generator really free?

Yes — MIT licensed. Download the JSON above, or grab it from the store (a free checkout) if you want updates delivered to you.

Can I sell or reuse it?

Yes, MIT means use it, ship it and change it. Attribution is appreciated but not required.

Which model should I use?

The default is gpt-4o-mini — fast and cheap. Swap the model name in the LLM node for any OpenAI-compatible endpoint.

Can I install it from n8n itself?

Yes. The workflow is published in the official n8n template gallery: Generate social content hooks with OpenAI GPT-4o-mini — search it in n8n's Templates, or open the link and click Use workflow.
